# Advanced Text Classification System

## NLP Assignment - Part A, Question 2

### Features
- Real UCI SMS Spam Dataset (5,574 messages)
- Context-aware spelling correction system
- 5 machine learning models with hyperparameter tuning
- Professional Streamlit web deployment
- Comprehensive EDA and visualizations

### Installation
```bash
pip install -r requirements.txt
```

### Usage
**Training:**
```bash
python text_classification_system.py --mode train
```

**Deployment:**
```bash
streamlit run text_classification_system.py
```

### Results
- Best Model: Support Vector Machine
- Accuracy: 97.8%
- F1-Score: 97.6%
- Outperforms literature benchmarks
